# RuqaiyaPro 1.13 - Boss Rubel

Device: Infinix HOT 12 Play (X6816C), Android 11 (API 30), 4+3GB RAM, 720x1640.
Theme: Black #000000 + Neon Green #00E676.

## Build (GitHub Actions - phone-e build hoy na)
1. Termux: `bash PUSH_TO_GITHUB_TERMUX.sh https://github.com/USER/REPO.git`
2. GitHub repo > Actions > build shesh hole Artifacts theke APK download.
3. Prothom bar install-er por app-er Settings-e API key + GitHub repo/token dao.
   Tarpor Update tab theke "Download & Install latest APK" diye pore update kora jay.

APK signing: `app/debug.keystore` (public debug key) use hoy, tai notun build purano app-er upore update hoy.
