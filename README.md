## 🚀 How to Build

### Option A: Import in Android Studio
1. Unzip `RuqaiyaPro-113-GOD-FINAL-FIX-FOR-BOSS-RUBEL.zip`.
2. Open Android Studio -> **Open an Existing Project** -> Select this directory.
3. Wait for Gradle Sync (Gradle 8.1.2 + JDK 17).
4. Connect Infinix HOT 12 Play with USB debugging enabled.
5. Click **Run** or build APK.

### Option B: Build directly on Phone using Termux
```bash
chmod +x TERMUX_BUILD.sh
./TERMUX_BUILD.sh
```
APK will be ready in `/sdcard/Download/RuqaiyaPro-BossRubel.apk`!
